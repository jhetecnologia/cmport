# CMPORT - versão estática para GitHub Pages

Esta pasta é uma primeira reconstrução estática baseada nos arquivos recuperados do WordPress: banco de dados, Elementor CSS e uploads.

## Importante
- Não publicar `wp-config.php`, SQL, backups ZIP ou arquivos PHP do WordPress.
- O objetivo desta etapa é reconstruir o site para GitHub Pages sem alterar deliberadamente o conteúdo original.
- Antes de apontar o domínio, compare visualmente com https://cmport.com.br/.

Arquivos principais: `index.html`, `servicos.html`, `quem-somos.html`, `contato.html`, `style.css`, `script.js`, `CNAME`.
